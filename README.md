# MANNA Event Calculator

Herramienta interna para preparar cotizaciones y compras de eventos.

## Cómo funciona

Es una página web estática. No hay servidor, cuenta de usuario ni base de datos compartida.

**Los datos se guardan localmente en cada navegador.** Cada dispositivo y cada navegador conserva su
propia copia de la información: lo que se edita en un teléfono no cambia lo que se ve en otra
computadora, y viceversa.

## Respaldos

**Se recomienda exportar respaldos regularmente**, y siempre antes de:

- cambiar de dispositivo o de navegador
- borrar los datos del navegador
- importar otra configuración

Desde la pestaña **Configuración**: *Exportar respaldo* genera un archivo `.json`;
*Importar respaldo* lo vuelve a cargar.

## Instalar en el teléfono

- **iPhone (Safari):** Compartir → *Añadir a pantalla de inicio*.
- **Android (Chrome):** menú ⋮ → *Añadir a pantalla principal*.

## Aviso

Este repositorio es público: cualquiera puede leer el código y la configuración inicial que la
herramienta necesita para funcionar. No se guarda aquí ninguna cotización, cliente ni dato de
operación real.
